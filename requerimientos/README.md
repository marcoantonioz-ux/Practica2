## Descripción

Este repositorio contiene una página web desarrollada utilizando HTML5 y CSS3 como parte de la actividad académica.

El proyecto corresponde a **SegundaOportunidAPP**, una plataforma web que busca facilitar la compra, venta y donación de artículos de segunda mano entre usuarios.

El sistema permite a los usuarios consultar publicaciones y comunicarse mediante mensajes de texto con compradores, vendedores y donadores relacionados con una publicación.

## Funcionalidad principal

* Consulta de publicaciones.
* Compra, venta y donación de artículos.
* Envío de mensajes de texto entre usuarios.
* Consulta del historial de conversaciones.
* Comunicación entre compradores, vendedores y donadores.

## Tecnologías

* HTML5
* CSS3
* Git
* GitHub

## Objetivo

Desarrollar una interfaz web sencilla y accesible que facilite la reutilización de artículos y la comunicación entre usuarios interesados en comprar, vender o donar productos.
